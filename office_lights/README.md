# Office lights

A small application that queries the [Sunrise sunset API](https://sunrise-sunset.org/api) and returns ON after sunset and OFF after sunrise.

## Usage

For regular usage to return 'ON' or 'OFF'

```bash
./office_lights
```

For debugging or troubleshooting a number of flags have been added that allow for manual checks. 

```bash
./office_lights --help
```

```
Determine if office lights should be ON or OFF based on sunrise and sunset times

Usage:
  office_lights [flags]

Flags:
      --date string        Date for sunrise/sunset calculation (DD-MM-YYYY) (default "29-10-2025")
  -h, --help               help for office_lights
      --latitude string    Latitude for sunrise/sunset calculation (default "50.930581")
      --longitude string   Longitude for sunrise/sunset calculation (default "5.780691")
      --time string        Time for sunrise/sunset calculation ('HH:MM:SS AM/PM') (default "7:23:44 PM")
      --tzid string        Timezone for sunrise/sunset calculation (default "Europe/Amsterdam")
  -v, --verbose            Enable verbose output

```

## Development 

### Setup development environment

Install go 1.22

```bash
sudo apt install golang-1.22
```

Install required modules

```bash
cd /projects/office_lights
go mod tidy
```

### Running in development

```bash
go run main.go
```

### Running tests

In the office_lights folder run the following command to run the tests.

```bash
go test ./cmd... -v
```

Note: The tests have been generated by Claude Sonnet 4.5

### Building

Execute the following command to build the application.
It creates a compiled executable with the module name, in this case "office_lights".

```bash
go build .
```

### GitHub Action

A github action is provided that builds this application and stores an executable for Linux amd64 in .github/workflows/go.yaml.
